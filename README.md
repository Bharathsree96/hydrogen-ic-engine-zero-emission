# hydrogen-ic-engine-zero-emission

# Hydrogen IC Engine — Zero Emission via 
# On-Demand Electrolysis ⚙️

## What is this project?
B.Tech final year group project (5 members) that designed 
and built a hydrogen-fuelled internal combustion engine. 
Hydrogen is produced on-demand via electrolysis — 
eliminating the need for fossil fuel and removing the 
explosion risk associated with stored hydrogen.

---

## Problem it solves
Conventional IC engines run on fossil fuels, producing 
harmful emissions. Earlier hydrogen engine designs 
required storing hydrogen — creating significant 
explosion risk. This project solves both problems by:
- Replacing fossil fuel entirely with hydrogen
- Generating hydrogen in real-time via electrolysis 
  (no storage needed)
- Producing zero tailpipe emissions (water only byproduct)

---

## Tools & Materials Used
| Component | Details |
|---|---|
| Base Engine | 97.2cc air-cooled bike engine |
| Electrolysis Chamber | Hand-built, stainless steel electrodes, KOH electrolyte |
| Safety System | Glass wool filter + one-way valve back-fire reducer |
| Frame | Mild steel fabrication |
| Fuel | Hydrogen (generated on-demand) |

---

## Key Results
- ✅ Successfully converted 97.2cc petrol engine 
  to run on hydrogen
- ✅ Zero tailpipe emissions — water as only byproduct
- ✅ Eliminated hydrogen storage risk through 
  on-demand electrolysis
- ✅ Estimated running cost ~$200/month vs 
  $500+/month for equivalent petrol engine
- ✅ Built and validated a custom back-fire safety 
  mechanism unique to this design

---

## How It Works
1. Electrolysis chamber converts water into hydrogen 
   using KOH electrolyte and stainless steel electrodes
2. Hydrogen passes through glass wool filter 
   (removes impurities)
3. One-way valve prevents back-fire risk
4. Hydrogen fed directly into carburetor 
   replacing petrol
5. Engine runs on hydrogen — emitting only water vapour
